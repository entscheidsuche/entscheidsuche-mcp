Model Context Protocol

entscheidsuche-mcp

MCP-Server fuer entscheidsuche.ch. Diese Instanz stellt die Suche in Schweizer Gerichtsentscheiden, Gerichtsurteilen und Rechtsprechung ueber einen MCP-Endpunkt bereit: Bundesgericht, BGer, BGE sowie kantonale Gerichte, Obergerichte und Verwaltungsgerichte.

MCP-Endpunkt 
https://mcp.entscheidsuche.ch/mcp
Verfuegbare Tools
  • search fuer Volltextsuche in Schweizer Rechtsprechung, case law und Gerichtsurteilen
  • search_by_case_number fuer exakte Suche nach Geschäftsnummern, Aktenzeichen, Urteilsnummern und BGE-Zitaten
  • get_document fuer den Abruf eines einzelnen Entscheids mit optionalem Volltext
  • list_hierarchy fuer Hierarchie-IDs und Trefferzahlen
  • list_facets fuer den lokalisierten Facettenbaum
  • server_info fuer Server- und Versionsinformationen
Typische Anwendungsfaelle
  • Bundesgerichtsurteil, BGE oder Gerichtsurteil thematisch suchen
  • Geschaeftsnummern wie BGE 142 III 1 oder 5A_396/2015 direkt nachschlagen
  • Schweizer Rechtsprechung zu ZGB, OR, StGB, SchKG oder Mietrecht recherchieren
  • Volltext eines einzelnen Entscheids fuer Analyse oder Zitat abrufen
Beispiel fuer Claude Desktop 
{
  "mcpServers": {
    "entscheidsuche": {
      "type": "http",
      "url": "https://mcp.entscheidsuche.ch/mcp"
    }
  }
}
